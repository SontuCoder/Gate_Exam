Propagation Delay (Tpd)

## Buffer

## Astable Multivibrator 
An astable multivibrator is a circuit that continuously switches between HIGH (1) and LOW (0) without any external trigger. It has no stable state, so it generates a square-wave clock signal.



## Bistable Multivibrator (Opposite of Astable) (Basic Memory Element)
   - Two stable states.
   - Does not oscillate on its own.
   - Changes state only when a trigger is applied.
   - Also known as a Flip-Flop.



## When Odd Number of Not Gate in Loop :-
   - Make **Bistable Multivibrator**
   - Time Periods (T)= 2N * Tpd, N = number of NOT Gate in Loop
   - Frequency (F)= 1/T = 1/(2N * Tpd)
