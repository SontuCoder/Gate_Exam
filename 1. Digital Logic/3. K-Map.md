# **Binary to Gray code or Cyclic Code or Unity Hamming distance code**:
For a binary number:
Bn ​Bn−1 ​… B1 ​B0​ 

## The Binary Code to Gray code:

First / MSB bit remains the same:
Gn​=Bn​

Remaining bits
Each Gray bit is the XOR of two adjacent binary bits:
Gi​=Bi+1​⊕Bi​

EX: 
Binary:  1 0 1 1
         ↓ ↓ ↓ ↓

# **K-MAP Rules**:

> [!IMPORTANT]
> - Minimize the **number of groups** → reduces the number of terms/gates.
> - Maximize the **size of groups** → reduces the number of variables in each term.

> [!NOTE]
> **Rules:**
>
> - Each group must contain $2^n$ cells, where $n = 0,1,2,3,\dots$
> - Valid group sizes are: `1, 2, 4, 8, 16, ...`
> - Make the **largest possible groups** first.
> - Every `1` must be covered by at least one group.
> - Overlapping groups are allowed.
> - Groups can wrap around the edges of the K-Map.
> - For each group, identify the variables that **remain constant**.
> - Eliminate the variables that **change within the group**.
> - For **SOP**, combine variables within a group using **AND (·)**.
> - Combine all groups using **OR (+)**.

> [!TIP]
>| AB \ CD | 00 | 01 | 11 | 10 |
>|:-------:|:--:|:--:|:--:|:--:|
>| **00** | `m₀` | `m₁` | `m₃` | `m₂` |
>| **01** | `m₄` | `m₅` | `m₇` | `m₆` |
>| **11** | `m₁₂` | `m₁₃` | `m₁₅` | `m₁₄` |
>| **10** | `m₈` | `m₉` | `m₁₁` | `m₁₀` |
 
> [!NOTE]
> **Don't Care (`X`) Rules:**
>
> - Treat `X` as either `1` or `0`, depending on which gives the simplest expression.
> - If an `X` helps create a **larger group**, treat it as `1`.
> - Otherwise, it may be treated as `0`.
> - A Don't Care cell does **not need to be covered**.


# **K-Map Rules for POS**

> [!IMPORTANT]
> For **POS (Product of Sums)** simplification:
>
> - Group the **0s** in the K-Map.
> - Each group represents a **Maxterm / Sum term**.
> - Combine all groups using **AND (·)**.

> [!NOTE]
> **Rules:**
>
> - Each group must contain $2^n$ cells.
> - Valid group sizes are: `1, 2, 4, 8, 16, ...`
> - Make the **largest possible groups** first.
> - Every `0` must be covered by at least one group.
> - Overlapping groups are allowed.
> - Groups can wrap around the edges of the K-Map.
> - Identify the variables that **remain constant** within each group.
> - Eliminate the variables that **change** within the group.
> - For each group, combine the remaining variables using **OR (+)**.
> - Finally, combine all groups using **AND (·)**.

> [!NOTE]
> **Don't Care (`X`) Rules:**
>
> - Treat `X` as either `0` or `1`, depending on which gives the simplest POS expression.
> - If an `X` helps create a **larger group of 0s**, treat it as `0`.
> - Otherwise, treat it as `1`.
> - A Don't Care cell does **not need to be covered**.

---

> [!NOTE]
> **Case Variable inside the cell:**
>
> - Step 1: Remove all variables and write the expression.
> - Step 2: Replace `1` with don't care and one variable is `1` and all other variables are `0`.
> - Step 3: Repeat Step 2 for the other variables.
> - Step 4: Write all the answers with the `+` sign.

---

> [!IMPORTANT]
> **🎯 Quick Summary:**
>
> - Implicant (I) -> Any valid group of 1s
> - Prime Implicant (PI) ->	Largest possible group; cannot expand further
> - Essential PI (EPI) -> Covers a 1 not covered by another PI
> - Selective PI (SPI) -> Choose if needed to cover remaining 1s
> - Redundant PI (RPI) -> Not needed because its 1s are already covered
