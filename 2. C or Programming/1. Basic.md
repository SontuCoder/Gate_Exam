# **Variables:**

## **Stodage type:**
| Storage Class | Scope | Lifetime | Default Value | Main Use |
|---|---|---|---|---|
| `auto` | Block | Until block ends | Garbage/indeterminate | Local variables |
| `register` | Block | Until block ends | Garbage/indeterminate | Request CPU register storage |
| `static` | Block/File | Entire program | `0` | Preserve value / restrict linkage |
| `extern` | Global/File | Entire program | `0`* | Access a global variable defined elsewhere |

> A static variable declear once, Next time it just pass this line.

# **Pointer:**

> [!NOTE]
> Without 'new' key if we declear a variable it uses 'stack' memory, with 'new' key it uses 'heap' memory.

## free() vs delete()

int *p = new int[10];
delete[] p;

int *p = new int;
delete p;

int *p = malloc(sizeof(int));
*p = 10;
